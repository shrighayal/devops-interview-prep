# Jenkins Interview Questions & Answers

## 🔹 General Questions

### 1. What is Jenkins?
Jenkins is an open-source automation tool used for CI/CD.

### 2. What is CI/CD?
CI → Continuous Integration  
CD → Continuous Deployment

---

## 🔹 Scenario-Based Questions

### 1. Build failing?
- Check console logs
- Verify dependencies
- Check Jenkinsfile

### 2. Pipeline slow?
- Use parallel stages
- Optimize build steps
- Use caching

### 3. Secure Jenkins?
- Use role-based access
- Store credentials securely
